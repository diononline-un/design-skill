# L1 · Voice

Design and copy are one decision: a beautifully set page with vague words is a tasteful
failure. `audit.py copy` finds the mechanical tells; this layer is for writing.

## Tone

Three concrete words: "calm, exact, a little warm", "fast, technical, dry". Clean,
modern, sleek, minimal and premium are not descriptions: they fit every template. If a
competitor could say it about themselves without it being false, the word is empty.

## Rules that carry the most weight

| Rule | Why |
|---|---|
| headlines say what it is and for whom | if it fits a competitor unchanged, it says nothing |
| a change says what it compares to: `+12 % vs last month` | a number without a reference is noise |
| errors name the problem and the recovery | "Invalid input" refuses; "That email is missing an @" helps |
| no exclamation marks in interface text | enthusiasm in a UI reads as panic |
| no greeting headlines ("Welcome back!") | the title names the context or period |
| short labels: `Search`, not `Search anything…` | the placeholder is not the label |
| no trailing periods on headings, labels, buttons, captions | weight without meaning |
| every claim checkable or cut | an unsourced number is a liability |
| mock data looks real: plausible names and figures | `[X]` or `123,456` signals a fake product |
| no hype: supercharge, seamless, unlock, magic, revolutionise, game-changing, AI-powered | it means "nothing specific to say" |

## Rhythm

The strongest machine tell in prose is uniform sentence length. Mix a four-word sentence
with a twenty-word one. Read it aloud: if every sentence has the same cadence, it is
machine-shaped whoever wrote it. Nobody has ever said "we empower businesses to unlock
their digital potential" out loud.

## Restore, don't only delete

Prose with only the slop removed reads sanded down. Put back: plain copulatives ("there
is", "it has", "was"); plain verbs (wrote, used, helped); definitive claims ("the only",
"the first"); qualifiers ("very", "perhaps", "tends to"); human joins ("as a result of",
"in order to"); specific nouns and real numbers; an opinion with a subject attached.
Models regress to the mean: "invented the first train coupling" becomes "a revolutionary
titan of industry". Every fix restores the specific thing that was flattened.

## Traps

- Replacing a vague claim with an invented specific: cut "leading provider", never write
  "trusted by 400 companies"; leave `[number needed]`.
- Rewriting a person's voice into another default: their quirks are brand data.
- Different tones per surface: the landing page and the error message are one product.
- Do not flag: perfect grammar, one em dash, one long sentence, jargon the audience uses.

## Naming

Name what the user controls, not the internals ("Notifications", not "Event delivery
preferences"). Verbs for actions, nouns for destinations: "Speichern" is a button, never
a tab. One name per concept everywhere: if the paper says "Betrieb", code, UI and emails
never say "Kunde", "Firma" or "Unternehmen" for it.
