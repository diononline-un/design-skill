# L1 · Voice

Design and copy are one decision. A beautifully set page with vague words is a
tasteful failure.

## Tone

**Three concrete words.** "Calm, exact, a little warm." "Fast, technical, dry."

**Not allowed as descriptions:** clean, modern, sleek, minimal, premium. They
describe every template, so they decide nothing. If a competitor could say the
same about themselves and it wouldn't be false, the word is empty.

## The copy rules that carry the most weight

| Rule | Why |
|---|---|
| **Headlines say what it is and for whom** | If it fits a competitor unchanged, it says nothing |
| **A change says what it compares to** — `+12 % vs last month`, never `+12` | A number without a reference is noise |
| **Errors name the problem and the recovery** | "Invalid input" is a refusal; "That email is missing an @ — check the address" is help |
| **No exclamation marks in interface text**, never `!!` | Enthusiasm in a UI reads as panic |
| **No greeting headlines** (`Welcome back, Damir! 👋`) | The page title should name the context or period |
| **Short labels:** `Search`, not `Search anything…` | The placeholder is not the label |
| **No trailing periods** on headings, labels, buttons, captions | They add weight without meaning |
| **Every claim checkable or cut** | A number with no source is a liability |
| **Mock data looks real** — plausible names and figures, never `[X]` or `123,456` | Fake-looking data signals fake product |
| **No hype words:** supercharge, seamless, unlock, magic, revolutionize, game-changing, AI-powered | They mean "we have nothing specific to say" |

## Sentence rhythm

The strongest machine tell in prose is **uniform sentence length**. Human writing
mixes a four-word sentence next to a twenty-word one.

Read it aloud. If every sentence has the same cadence, it's machine-shaped
regardless of who wrote it.

## The two tests

**The swap test.** Paste the copy onto a competitor's site. Nothing breaks ⇒ it
says nothing about this product.

**The read-aloud test.** Does a person say this sentence out loud? "We empower
businesses to unlock their digital potential" — nobody has ever said that.

## Traps

- **Replacing a vague claim with an invented specific one.** You may cut "leading
  provider"; you may not replace it with "trusted by 400 companies". Leave a
  marked gap: `[number needed]`.
- **Rewriting a person's voice into a different default.** Cut the machine habits,
  keep the person. Their quirks are data about the brand, not noise.
- **Consistency across surfaces.** The tone on the landing page and the tone in the
  error message are the same product speaking.

## Naming things

- **Name what the user controls, not the system's internals.** "Notifications",
  not "Event delivery preferences".
- **Verbs for actions, nouns for destinations.** A button that says "Speichern"
  is a button. A tab that says "Speichern" is a mistake.
- **One name per concept, everywhere.** If the paper says "Betrieb", the code,
  the UI and the emails all say "Betrieb" — not "Kunde", "Firma", "Unternehmen"
  in three places.
