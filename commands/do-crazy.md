# do-crazy

**Job:** off-distribution design, after real market research. Not "more styling" —
a different *world*.

**Loads:** `layers/06-research.md` (mandatory, in full) + `layers/00-craft-floor.md`
+ mode layer.

**The test:** if the result would look at home next to the competitors you
researched, `do-crazy` failed. Not "failed to be crazy" — failed to be *decided*.

---

## 0. The precondition

`do-crazy` without research produces noise, not a direction. The research is not
ceremony — it's what separates a bold idea from a random one.

If the user wants "just make something wild, skip the research": do it, and label
the result **unresearched** in the report. It will feel arbitrary, and saying so
up front is honest.

## 1. Research — the full protocol

Run `layers/06-research.md` steps 1–6. Do not shorten. The output you need:

- **8–12 specific nouns** from the subject's physical world (generic industry
  words crossed out)
- **The audience's real trust signals** (researched, not assumed)
- **The category's visual language**, classified: uniform / chaotic / outdated
- **5–10 references**, each reduced to a transferable quality
- **The anti-default check** — what you're deliberately not doing

## 2. Generate three worlds, not three colours

A "world" is a structural idea, not a palette. Three genuinely separate worlds,
each of which could carry the whole site.

For each world, write:

```
World:      <name it — "the cadastral drawing", "the roof at 6am">
The move:   <the one structural thing the category would not attempt>
Material:   <what the page is made of — paper, glass, light, data>
Type:       <character, not the face>
Composition:<where the subject sits — a real spatial idea, not "split hero">
The proof:  <the one thing only this product can show, and how it's shown>
Cost:       <what this makes harder — conversion, load time, legibility>
Dies if:    <the condition under which this world fails>
```

**Each world must be viable before it's proposed.** A direction that needs assets
you don't have, claims that aren't true, or performance you can't afford is not a
bold direction — it's an unfinished one.

## 3. The anti-default gate — mandatory

Before showing anything, check every world against:

| Default | Escape test |
|---|---|
| Violet gradient + glass | Obvious. Avoid. |
| Cream + terracotta + serif | The tasteful default. If your world reads as "editorial warm", check again. |
| Near-black + acid accent | The serious-tech default. |
| Broadsheet/editorial cosplay | Newspaper type on a non-publication. |
| Mono micro-labels + `A·B·C` + `WORD — fragment` | Template chrome. |
| One big beautiful photo + centred headline + pill CTA | The "designed" default. |
| Engraving/woodcut as a filter | Only if the *whole* brand lives there. |

> **Would I have arrived here for any similar project?**
> If yes, revise it and state what changed. Do this for each of the five lines.

## 4. Show three, with a recommendation

```
World A — <name>
  The move: …
  Cost: …
  My pick if: <condition>

World B — <name>
  …

World C — <name>
  …

Recommendation: B, because <reason tied to the research, not to taste>.
```

**Then stop.** `do-crazy` is the command where the client must choose — the whole
point is that it's their risk, and picking for them removes the agency the
direction needs.

## 5. Build the winner at full commitment

Half-committed bold work is the worst outcome: it reads as a mistake rather than a
decision.

- **One dominant move**, executed completely.
- **The chrome stays quiet** so the move can be loud. Richness in one or two
  places, not spread over buttons and borders.
- **Craft floor still applies.** Contrast, states, responsive, keyboard — a bold
  page that fails the floor is just broken with confidence.
- **No new decoration to replace the removed decoration.** Swapping one trend for
  another is not departure.

### When the bold move fights usability

Name the trade and offer the split:

> The world wants the navigation inside the drawing, which costs ~1 s of
> discovery. Option A: full commitment (the drawing carries the nav). Option B:
> drawing + conventional nav below. A is the design; B is the compromise.

Never silently degrade the idea, and never silently break the task.

## 6. The honesty gate before shipping

Bold work fails in one specific way: it's beautiful and it doesn't work.

- **Does the primary action still read as a primary action?**
- **Can a keyboard user complete the task?**
- **Does it survive 390px?** (The most common casualty.)
- **Does it load?** A world that needs 4 MB of imagery is a world only you see.
- **Is anything claimed that isn't true?** This is where bold becomes dishonest.

If any of these fail, the design isn't done — it's deferred.

## 7. Report

```
Mode: Persuade
Research: <3 key findings — the nouns, the trust signal, the category read>
World chosen: <name> — the move: <one line>
Rejected: <the other two, in one line each, with why>
Anti-default: <what I checked against and what changed>
Cost accepted: <what this makes harder, and the mitigation>
Score: 81/100 — distinction 4, hierarchy 4, content 4, usability 3
```

## Common failures

- **"Crazy" as a synonym for "more effects".** Glow, glass and motion are not a
  world.
- **Skipping research** and landing on the current tasteful default with more
  confidence.
- **Three worlds that are one world in three palettes.** Then you haven't generated
  alternatives, you've generated variations.
- **Committing 40 %.** The most expensive outcome: all of the risk, none of the
  payoff.
- **Bold that doesn't work.** If the task fails, it isn't ambitious, it's unfinished.
- **Keeping the old hero because it converts.** Then don't run `do-crazy` — run
  `do-design-renew` and keep the hero on the survival list.
